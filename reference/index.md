# Package index

## Pedigree statistics

- [`ped_stats()`](https://juliengamartin.github.io/pedtricks/reference/ped_stats.md)
  : Calculates a range of statistics of pedigrees
- [`summary(`*`<ped_stats>`*`)`](https://juliengamartin.github.io/pedtricks/reference/summary.ped_stats.md)
  : Post-processes output from ped_stats
- [`h2_samp_var()`](https://juliengamartin.github.io/pedtricks/reference/h2_samp_var.md)
  : Calculates expected sampling variance of a given \$h^2\$ from the A
  matrix of a pedigree, based on the method of Visscher and Goddard 2015
  Genetics

## Pedigree visualization

- [`draw_ped()`](https://juliengamartin.github.io/pedtricks/reference/draw_ped.md)
  : Produce a graphical representation of a pedigree
- [`draw_pedA()`](https://juliengamartin.github.io/pedtricks/reference/draw_pedA.md)
  : Produce a graphical representation of the relatedness matrix of a
  pedigree
- [`ggpedigree()`](https://juliengamartin.github.io/pedtricks/reference/ggpedigree.md)
  : ggpedigree: Plotting tool for simple and complex pedigrees.
- [`plot(`*`<ped_stats>`*`)`](https://juliengamartin.github.io/pedtricks/reference/plot.ped_stats.md)
  : Plot output from ped_stats

## Pedigree manipulation

- [`convert_ped()`](https://juliengamartin.github.io/pedtricks/reference/convert_ped.md)
  : Converts a pedigree with individuals specified as factors to a
  numeric pedigree
- [`fix_ped()`](https://juliengamartin.github.io/pedtricks/reference/fix_ped.md)
  : Manipulating pedigrees to prepare them for requirements of
  subsequent analyses Prepares a pedigree to conform with requirements
  of many softwares used in quantitative genetic analysis, as well as
  for many of the functions in pedtricks.

## Pedigree simulations

- [`genome_sim()`](https://juliengamartin.github.io/pedtricks/reference/genome_sim.md)
  : A function to simulate QTL and/or SNP data.
- [`micro_sim()`](https://juliengamartin.github.io/pedtricks/reference/micro_sim.md)
  : Simulates microsatellite data across a pedigree.
- [`phen_sim()`](https://juliengamartin.github.io/pedtricks/reference/phen_sim.md)
  : A function to simulated phenotypic data

## Pedigree example
