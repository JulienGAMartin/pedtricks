# Example dataset for pedtricks examples and tutorial

This contains pedigree and life history data of a fictional population.
The data are relevant to power and sensitivity analyses for quantitative
genetic studies of natural populations.

## Usage

``` r
gryphons
```

## Format

An object of class `data.frame` with 4918 rows and 9 columns.
